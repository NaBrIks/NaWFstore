# NaWFstore

- This is an independent MIT library extracted from ESP32-BLETPMS-and-more at `de88eb1`.
- Keep the portable core independent of ESP-IDF and application code. Keep web, display and product policy in consumers.

- Preserve secret-free source, examples and diagnostics. Use the workspace C/C++ style and the checked-in Uncrustify profile.
