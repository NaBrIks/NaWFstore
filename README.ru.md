# NaWFstore

[English](README.md) | Русский

Библиотека для ESP-IDF хранит сети в NVS, выбирает профиль по приоритету и восстанавливает соединение. Один владелец вызывает менеджер и `poll()`. Проект отвечает за интерфейс и способ первичной настройки.

Таймер работает в библиотеке. `enable(0)` включает Wi-Fi бессрочно, положительное значение задаёт длительность текущего сеанса. При истечении таймера выполняется обычное выключение Wi-Fi. У временной точки доступа есть свой таймер.

По умолчанию `StartupPolicy::application` берёт настройку старта из проекта, а `set_startup` меняет её только в памяти. Проект может сохранить её в своих настройках. Для самостоятельного устройства можно выбрать `StartupPolicy::stored` и сохранять стартовый режим вместе с сетями. MAIN использует этот режим для совместимости. NaSDeck берёт сети из того же NVS и задаёт свой режим без таймера. `ConnectionTiming` позволяет переопределить длительность попытки и паузы. Значения по умолчанию — 20 с, 250 мс между сетями и 15 с после полного круга.

На общей LCD7 ESP32-S3 16 МиБ сохраняйте раздел `nvs` по адресу `0x9000` размером `0x6000` (24 КиБ) и установленную таблицу разделов. Используются namespace `nawfstore`, слоты `cfg0/cfg1`, формат `NWF1`. Настройка действует на этой плате после смены приложения. Другие платы настраиваются отдельно. Лимит добавления `NAWFSTORE_MAX_PROFILES=5` общий для рабочей области, старые наборы до восьми сетей поддерживаются.

Для PlatformIO используйте `framework = espidf` и `lib_deps` с закреплённой ревизией репозитория. Для локальной проверки подходит `symlink://` плюс абсолютный путь к библиотеке. Для ESP-IDF используйте CMake или Component Manager. Требования к компонентам SDK и параметры сборки описаны в английской инструкции.

При `nvs_save_uncertain` перезапустите устройство перед повторным изменением. После сбоя контрольного чтения новая запись могла уже попасть во flash. Формат защищён CRC, шифрование NVS настраивается отдельно на уровне устройства. Секреты в Git и обычную диагностику не попадают.
